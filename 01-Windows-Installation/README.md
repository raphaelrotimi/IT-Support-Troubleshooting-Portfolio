Windows Installation Using a Bootable USB

IT Support Portfolio | Project 01

Overview

This project explains how to install the Windows operating system using a bootable USB flash drive.

A bootable USB allows a computer to start the Windows installation process without using a DVD. This method is commonly used by IT support technicians when installing or reinstalling Windows.

Requirements

Before starting the installation, prepare the following:

- A USB flash drive (minimum 8GB recommended).
- Windows 10 or Windows 11 installation media.
- A working computer.
- A Windows ISO file or Media Creation Tool.
- An internet connection for downloading installation files.

Important: Creating bootable installation media normally erases the USB drive. Back up important files before proceeding.

Installation Steps

Step 1: Prepare the Bootable USB

Download the official Windows installation media from Microsoft's website.

Use the Media Creation Tool or another suitable utility to create a bootable USB drive.

Step 2: Connect the USB Drive

Insert the bootable USB flash drive into the computer where Windows will be installed.

Step 3: Open the Boot Menu

Restart the computer and press the appropriate boot-menu key during startup.

Common boot-menu keys include:

- F12
- F9
- F11
- Esc

The correct key depends on the computer manufacturer.

Step 4: Select the USB Drive

Choose the USB flash drive from the boot menu.

The computer should start loading the Windows installation environment.

Step 5: Begin Windows Installation

Select your preferred:

- Language
- Time and currency format
- Keyboard layout

Click Install now and follow the installation instructions.

Step 6: Complete the Installation

Follow the on-screen instructions to select the installation drive and complete Windows setup.

After installation, configure the initial Windows settings and install the necessary drivers and updates.

Common Installation Problems

Problem| Possible Solution
USB not detected| Check USB connection and boot settings
Boot menu unavailable| Confirm the correct boot-menu key
Installation cannot find a drive| Check storage and BIOS/UEFI settings
Installation freezes| Check the USB drive and installation media

Expected Result

Successful installation of Windows from a bootable USB drive, followed by initial system configuration.
