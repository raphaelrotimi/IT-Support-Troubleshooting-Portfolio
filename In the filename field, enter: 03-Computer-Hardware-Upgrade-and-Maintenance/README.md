Computer Hardware Upgrade and Maintenance

IT Support Portfolio | Project 03

Overview

This project documents practical computer hardware upgrade and maintenance activities, demonstrating hands-on experience with computer components, storage devices, and internal system maintenance.

Hardware Maintenance Activities

1. RAM Upgrade

Upgrading computer memory (RAM) to improve system performance and support smoother multitasking.

2. SSD Replacement

Replacing an existing solid-state drive to improve storage performance and system responsiveness.

3. Hard Drive Installation

Installing a new hard disk drive (HDD) to provide additional storage capacity.

4. Internal Component Cleaning

Cleaning internal computer components to remove accumulated dust and support proper airflow and cooling.

Practical Skills Demonstrated

- Computer hardware identification
- RAM installation and upgrades
- SSD replacement
- Hard drive installation
- Internal component cleaning
- Basic hardware maintenance
- Computer troubleshooting

Importance of Hardware Maintenance

Regular hardware maintenance and appropriate component upgrades can help improve computer performance, reliability, storage capacity, and cooling.
