Basic Network Troubleshooting Using Windows Command Prompt

IT Support Portfolio | Project 04

Overview

This project demonstrates basic network troubleshooting techniques using Windows Command Prompt and built-in networking utilities.

Network troubleshooting helps IT support technicians identify connectivity problems, inspect network configurations, and diagnose common internet connection issues.

Network Troubleshooting Commands

1. Checking Network Configuration with IPConfig

The "ipconfig" command displays the computer's network configuration.

Command:

ipconfig

To display detailed network information:

ipconfig /all

This helps identify:

- IP address
- Subnet mask
- Default gateway
- DNS server information

2. Testing Network Connectivity with Ping

The "ping" command checks whether another device or server is reachable over a network.

Command:

ping google.com

This helps identify:

- Network connectivity problems
- Connection timeouts
- Packet loss
- Response times

3. Checking DNS Resolution with NSLookup

The "nslookup" command checks whether a domain name can be resolved to an IP address.

Command:

nslookup google.com

This helps investigate DNS resolution problems.

4. Troubleshooting Wi-Fi Connectivity

Basic Wi-Fi troubleshooting includes:

- Confirming that Wi-Fi is enabled.
- Checking whether the computer is connected to the correct network.
- Restarting the router when appropriate.
- Checking the network configuration.
- Testing connectivity using "ping".

5. Identifying Common Network Problems

Problem| Possible Troubleshooting Action
No internet connection| Check Wi-Fi and network configuration
IP address problem| Inspect using "ipconfig"
DNS resolution failure| Test using "nslookup"
Connection timeout| Test connectivity using "ping"
Weak Wi-Fi signal| Check distance from the router
